# NIRU DARK RITUALS I

**32 dark ambient tones for the Roland GAIA 2**

Created by **Nicklas Rudolfsson** · 2026

A collection of evolving drones, spectral choirs, ritual textures, industrial
soundscapes, bells and sub-bass for dark ambient performance and composition.
The download contains a 32-tone bank and the same tones as individual files.

This is an **early version** and may be updated. Created for my own music and
shared freely for use in yours; see the notice below regarding Roland-owned material.

> **Hardware testing pending:** the files have passed software checks, but have
> not yet been imported or auditioned on a physical GAIA 2. Sound descriptions
> describe the design intent rather than verified listening results.

## Install

1. Back up any user tones you want to keep: importing overwrites the selected slots.
2. Use a USB drive formatted by the GAIA 2 or a compatible FAT32 drive.
3. Copy `NIRU_DARK_RITUALS_I.svz` to `ROLAND/SOUND` on the drive.
4. Connect the drive to the GAIA 2, then choose **MENU → File → Import**.
5. Select the bank, mark the desired tones and destination slots, and confirm.

Individual `.svz` files in `patches/` can be imported in the same way.
